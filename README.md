# מה כתוב בכוכבים / What the stars say — אפליקציית Ionic

Ionic 8 + React 18 + Vite + Capacitor 7. כל החישובים מקומיים, בלי שרת.

## הרצה

```bash
npm install
npm run dev        # דפדפן, http://localhost:5173
npm test           # בדיקות לליבת החישובים (Node 22+)
```

## בנייה לנייד

```bash
npm run build
npx cap add android   # או ios (דורש Xcode)
npx cap sync
npx cap open android
```

לפני פרסום, לשנות את `appId` ב־`capacitor.config.ts`.

## מבנה

- `src/core/astro.ts` — ליבת החישובים, TypeScript טהור ללא תלויות. כל טקסט תוכן מוגדר כ־`{ he, en }`. אותו קובץ בדיוק משמש גם את גרסת האתר.
- `src/core/i18n.ts` — מחרוזות הממשק בשתי השפות (משותף לאתר ולאפליקציה), זיהוי שפת המכשיר וכיוון.
- `src/lang.tsx` — `LangProvider` ו־`useLang()`: שפה נוכחית, מחרוזות, החלפה ושמירה. מעדכן `lang`/`dir` על `<html>` כך ש־Ionic הופך כיוון לבד.
- `src/pages/` — שלושה טאבים: המפה שלי, התאמה זוגית, טארוט.
- `src/core/tarot.ts` — 22 קלפי הארקנה הגדולה (עברית/אנגלית), משיכה אקראית וקלף לידה.
- `src/components/TarotCard.tsx` — קלף שמתהפך בלחיצה.
- `src/components/ZodiacWheel.tsx` — גלגל המזלות המסתובב.
- `src/storage.ts` — שמירת הקלט האחרון דרך `@capacitor/preferences`.
- `src/theme/variables.css` — פלטה בהירה/כהה.

## הערות חישוב

- לוח עברי ומזל סיני מחושבים דרך `Intl` (לוחות `hebrew` ו־`chinese` של ICU) — בלי ספריות ובלי טבלאות תאריכים.
- "נולדתי אחרי השקיעה" מקדם את התאריך העברי ביום.
- מזל עברי ושבט לפי חודש הלידה העברי (מסורת אחת מכמה).
- נומרולוגיה: מסלול חיים עם מספרי מאסטר 11/22/33; מספר שם לפי גימטריה לעברית ופיתגוראית ללטינית.

## שפות

- ברירת המחדל נקבעת לפי שפת המכשיר (עברית אם `he`, אחרת אנגלית), ובחירה ידנית נשמרת.
- הוספת שפה: להוסיף מפתח ל־`Lang`, להשלים את השדות ב־`astro.ts` ומילון ב־`i18n.ts`. `npm test` נכשל אם חסר תרגום או מפתח.
- שם האפליקציה במסך הבית נקבע בנייטיב: `strings.xml` באנדרואיד (`values/` ו־`values-iw/`) ו־`InfoPlist.strings` ב־iOS.

## טארוט

- משיכה עם `crypto.getRandomValues` וערבוב Fisher–Yates, בלי הטיית מודולו. הבדיקות מוודאות שאין קלף כפול בפריסה ושהפיזור אחיד.
- פריסות: קלף אחד, או עבר/הווה/עתיד. אפשר לכבות קלפים הפוכים.
- לכל קלף יש משמעות רגילה והפוכה והקבלה אסטרולוגית (מסורת Golden Dawn). אם הקלף מקביל למזל של המשתמש, זה מסומן.
- קלף לידה: סכום כל ספרות תאריך הלידה, מצומצם עד 22 (22 = השוטה). מוצג במפה האישית.

## אסטרולוגיה מתקדמת (טאב "אסטרולוגיה")

שבע שיטות, כולן מחושבות מקומית במכשיר, בלי שרת:

| שיטה | מה מחושב |
|---|---|
| מפת לידה | כוכבים במזלות ובבתים (פלסידוס), היבטים, איזון יסודות, שליט המפה, עוצמות |
| קרמתית | ראש וזנב הדרקון (ממוצע), כוכבים בנסיגה, שבתאי, נקודת המזל ונקודת הרוח |
| תחזית | טרנזיטים פעילים, סריקת 12 חודשים של מעברים מדויקים, חזרה סולארית, קידומים משניים |
| סינסטרי | היבטים בין המפות עם מדד הרמוניה, כוכבים בבתים של השני, מפת קומפוזיט |
| הוררית | מפת רגע השאלה, תקפות, מייצגים (שליטים מסורתיים), השלמה, ירח ריק ממהלך, העברת אור |
| בחירת מועד | סריקה שעתית עד 60 יום לפי כללים מסורתיים, 6 המועדים הטובים ותקופות נסיגה |
| עולמית | מפות לאומיות (ישראל, ארה״ב, בריטניה, צרפת, גרמניה, הודו) או אירוע מותאם, טרנזיטים, כניסות, מחזורים וליקויים |

המנוע: `astronomy-engine` (MIT) למיקומי הכוכבים. בתים, אופק, ראש דרקון ונקודות מחושבים ב-`src/core/chart.ts`.
הדוחות נבנים ב-`src/core/techniques.ts` ומוצגים דרך `src/core/render.ts`, אותו קוד שמשמש את האתר.
מקומות: כ-70 ערים מובנות ב-`src/core/places.ts`, או קואורדינטות ואזור זמן ידניים. אין גיאוקודינג.

מגבלות ידועות: ראש דרקון ממוצע (לא אמיתי), בלי כירון, הוררית בגרסה פשוטה של שיטת לילי,
ציוני בחירת מועד היוריסטיים, ושעות הקמה של מדינות שנויות במחלוקת. בלי שעת לידה אין בתים ואופק.
